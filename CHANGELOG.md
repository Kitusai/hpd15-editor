# Changelog

## 1.0 — 2026-11-15

First public release of the Swift editor, replacing the Electron prototype `hpd15-studio`.

- Set screen with the HPD-15 surface, pad selection by click or by playing, 601 instruments, live per-pad editing.
- Loading of the 160 factory presets and 80 user patches.
- Set effects screen (reverb, multi-effect, routing).
- Library of `.hpdset` files: Save / Save as, send to the HPD-15 with read-back check, duplicate, Trash.
- Detection of patch changes made on the instrument.
- English and French interface.
- Universal app (Intel + Apple Silicon) built without a full Xcode install, custom icon.
- Console diagnostics tool and hardware-free self-tests.
